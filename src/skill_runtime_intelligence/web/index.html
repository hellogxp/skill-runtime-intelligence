      READING GUIDE What do these terms mean? Evidence grade, activation, attribution, and gaps
      Observed

      A direct source record says the event happened, with a time and source locator.

      Derived

      A deterministic rule links or summarizes observed records; it adds no hidden fact.

      Unsupported

      This adapter cannot expose the signal, so the product makes no occurrence judgment.

      Skill enablement (Activation)

      How this Skill became active for the request: explicitly invoked, automatically selected, always enabled, or unknown. It does not mean the first tool call.

      Attributed events

      Events linked to this SkillRun by source identity, exact Skill path, or active run scope. Attribution is association, not causality.

      First evidence gap

      The earliest observable stage with no matching signal before later evidence appears. Missing evidence is not proof the step did not happen.
